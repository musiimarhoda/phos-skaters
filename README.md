# Phos Skaters website

One static page (index.html). No build step.

## Put it live on Vercel (about 2 minutes)
1. Go to vercel.com and sign in (free Hobby plan is fine).
2. Click Add New > Project.
3. Either import a GitHub repo containing this folder, or install the Vercel CLI and run `vercel` inside this folder.
4. Framework preset: Other. Leave build settings empty. Click Deploy.
5. To use your own domain (e.g. skaters.phoscreatives.africa): Project > Settings > Domains.

## Swap in your photos
Replace the two `<div class="photo">` placeholders in index.html with
`<img class="photo" src="kfc.jpg" alt="Phos Skaters at the KFC opening">`
and drop the image files next to index.html.
